# Before sending, and what to file when ADR replies

## Before sending
- [ ] Entity has a name, or the host institution sends it with the entity described as "forming" (`docs/decisions/S-152-entity-checklist.md`, section 1)
- [ ] A real person signs, with a monitored mailbox on the entity's own domain (not personal)
- [ ] Funder sentence decided (S-152 decision: disclosed)
- [ ] Recipient address taken from ADR / MyNeta's official contact page
- [ ] No data attached; the email asks permission "to consider" and does not describe plans as decided
- [ ] Counsel has had a chance to look at it, if engaged (optional but sensible, since the reply governs defamation-sensitive wording; gate row 15)

## What the product does meanwhile
Link-outs only, which is complete and working. No affidavit figures appear until consent is on file (`docs/decisions/02-affidavit-link-outs.md`). The ECI affidavit portal's own terms are checked separately before anything beyond a link.

## When a reply arrives
* **Consent for selected fields (item 1):** show only those fields and conditions, with attribution and a link. Same fields in the same layout for every candidate; no ranking, scoring or filtering by assets or cases. Wording around declared cases follows their conditions and counsel's view.
* **Consent for bulk download (item 2):** a separate build (dated import, licence recorded in the data register) and a new decision record. Nothing is downloaded before the reply is filed.
* **Refusal or silence:** link-outs stay as they are. Follow up once after ____ weeks, then treat silence as no.
